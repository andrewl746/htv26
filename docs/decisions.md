- 2026-10-17 · Andrew · `AVG_HEIGHT` is the massing height, for extruding neighbouring buildings and for the larger-building test; `MAX_HEIGHT` is not used. Why AVG and not MAX: `MAX_HEIGHT` is a building's highest point, so a roof ridge, chimney or parapet sets it (sample building: `AVG_HEIGHT` 5.69 m, `MAX_HEIGHT` 8.59 m); extruding that as a flat box would draw a pitched-roof house about a storey too tall beside the design (2.9 m in that sample) and push ordinary houses toward the larger-building threshold, while the average is the closer single number for a flat extrusion. The neighbours stay labelled illustrative · source read: MASTERSPEC Appendix H row "3D Massing file name, size, fields and height field" (CKAN `package_show`; the 2025 shapefile `3DMassingShapefile_2025_WGS84.zip` downloaded and its DBF header read: 428,184 features, fields `MIN_HEIGHT, MAX_HEIGHT, AVG_HEIGHT, HEIGHT_MSL, SURF_ELEV, HEIGHT_SRC, BLDG_SRC, LONGITUDE, LATITUDE`, no id column, `.prj` Web Mercator EPSG:3857) and the Appendix G sample values · how to change it: switch the one height field in the pipeline's massing step and the engine's larger-building test, then retune the larger-building threshold in contracts/engine_config.json with the A8 test lots.
